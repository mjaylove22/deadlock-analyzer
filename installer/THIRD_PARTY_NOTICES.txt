Tesseract OCR (the "_internal\tesseract" folder)
------------------------------------------------
Tesseract 5 and the English model, unmodified, from the Windows build by UB Mannheim
(https://github.com/UB-Mannheim/tesseract/wiki). Only the files Tesseract needs to read English
text are included. That build uses libraries from MSYS2; the source code of every library below is
available from https://packages.msys2.org (search for the package name with a "mingw-w64-" prefix).
Each library is a separate DLL that can be replaced with another build of the same library.
